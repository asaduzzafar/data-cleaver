Data Cleaver 1.0.0 is the first release. It opens CSV files too big for a
spreadsheet (hundreds of megabytes, millions of rows) on your own Windows PC.
Nothing leaves your computer: no server, no account, no upload.

## Install

1. Download **`DataCleaver-Setup.exe`** below. `DataCleaver-Setup.exe.sha256`
   holds its checksum.
2. Run it. The installer isn't code-signed, so Windows SmartScreen may say
   *"Windows protected your PC"*. Click **More info**, then **Run anyway**.
3. It installs for your user only and doesn't ask for administrator rights.

Needs 64-bit Windows 10 (version 1809 or later) or Windows 11, with Microsoft
Edge WebView2 (Windows 11 already has it; on older Windows 10 the app says if
it's missing and where to get it). The first launch prepares a one-million-row
sample dataset in about 15 seconds; turn it off in **Settings → Enable demo
data**.

## What's in it

- **Load** a CSV into a fast columnar copy. Columns that look like IDs are
  kept as text, so account and order numbers keep their leading zeros. Rows
  the parser can't read are set aside and listed, never silently dropped.
- **Profile** every column: type, how full it is, distinct values, range and
  distribution, with leads worth a look pulled to the top. List any column's
  distinct values with their counts.
- **Preview** the first rows as stored, or a repeatable random sample.
- **Outliers**: numeric extremes, rare categories, blanks and repeating keys,
  each opening exactly the rows behind it.
- **Slice, pivot, join and SQL.** Filters read as sentences, joins check
  their keys before they run, and SQL completes table and column names.
  Expensive queries ask before they run.
- **Save** any result as a table that remembers where it came from. Reload a
  source and every result built on it, however many steps back, is flagged
  stale. Big saves run in the background with progress.
- **Export** to `.xlsx`, `.csv` or Parquet, into a folder you choose.
- **Picks up where you left off**: each file keeps its step, settings, results
  and SQL while you move between files.
- **Back up** your saved work from Settings. The app keeps a log in its data
  folder for troubleshooting.
